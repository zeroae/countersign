# @zeroae/countersign

Run `npx @zeroae/countersign` on a desktop to open the macOS or Windows installer or launch the Linux AppImage. npm installs the matching binary as an optional dependency. Both x64 and ARM64 are supported on each operating system. The launcher uses the binary from the installed npm package.

To locate the downloaded file, run `npx @zeroae/countersign --print-path`. Unsigned installers are subject to your operating system’s application security settings.

[Install and pair your desktop](https://zeroae.github.io/countersign/companion/)
