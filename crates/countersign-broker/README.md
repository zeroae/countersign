# countersign-broker

Run the approval service for a Countersign integration. The Broker pairs desktop Companions, records user grants and issues bounded leases to authenticated Gateways. The reference server stores its state in SQLite.

```sh
cargo install --locked countersign-broker
```

[Self-host the Broker](https://zeroae.github.io/countersign/operate/) · [Integrator backend API](https://zeroae.github.io/countersign/reference/api/)
