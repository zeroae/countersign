# countersign-native

Build the Node-API addon used by the Electron Companion to enumerate native certificate identities, sign approved TLS handshakes and protect pairing credentials. Build for the operating system and CPU architecture of the Electron process that loads the addon.

[Build the Companion](https://zeroae.github.io/countersign/develop/) · [Tested platforms and providers](https://zeroae.github.io/countersign/reference/support/) · [Install the desktop application](https://zeroae.github.io/countersign/companion/)
